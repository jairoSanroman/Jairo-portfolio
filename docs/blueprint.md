# **App Name**: Jairo Sanromán Portfolio

## Core Features:

- Dynamic Hero Section: Prominently display personal information, professional title, and key call-to-action buttons (CV, GitHub, LinkedIn, Contact).
- Comprehensive 'About Me' and Experience Display: Dedicated sections to present a personal narrative, detailed work history, and educational background in an easily digestible format.
- Interactive Skills Showcase: Visually organized presentation of technical competencies, including languages, frameworks, databases, and tools, categorized for clarity.
- Project Showcase with Detailed Views: A gallery of projects, each featuring a brief overview, a detailed breakdown upon selection, and accessible links to live demonstrations or code repositories.
- AI-powered Skill-Project Connector Tool: A tool that uses AI to automatically highlight projects most relevant to a specific technical skill when a potential employer interacts with the skills section, providing instant alignment.
- Direct Contact Form: A fully functional form allowing recruiters and interested parties to easily send messages directly to Jairo Sanromán.
- External Resource Links: Conveniently provides direct links to Jairo's CV (downloadable), GitHub profile, and LinkedIn presence.

## Style Guidelines:

- Primary accent color: A vibrant electric blue (#0062FF) to highlight interactive elements and key information against a dark background, evoking innovation and tech proficiency.
- Background color: A deep, desaturated blue-gray (#161C1E) providing a modern dark theme that ensures readability and a sophisticated feel.
- Secondary accent color: A bright neon green (#00FF6A) used for subtle highlights, interactive states, and to provide dynamic visual contrast alongside the primary blue.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, techy aesthetic, suitable for impactful titles and section headers.
- Body font: 'Inter' (sans-serif) for its neutrality, readability, and clean lines, ideal for longer text blocks like 'About Me' and project descriptions.
- Utilize a consistent set of minimalist, line-art style icons for external links (GitHub, LinkedIn, Email) and functional elements, maintaining a sleek, professional appearance.
- Adopt a clean, structured, and responsive layout with ample whitespace to ensure content readability and optimal viewing across all device sizes. A dedicated area for a professional profile photograph will establish an immediate personal connection.
- Implement subtle animations and smooth transitions for page navigation and interactive elements, enhancing user experience without distracting from the content.
