# Jairo Sanromán - Portfolio Profesional

Este es mi portafolio profesional como Desarrollador de Aplicaciones Multiplataforma (Junior), construido con **Next.js 15**, **Tailwind CSS**, **ShadCN UI** e integrado con **Google GenAI (Genkit)** para funcionalidades inteligentes.

## Características

- 🚀 **Tecnologías Modernas**: Next.js 15 (App Router), TypeScript y Tailwind.
- ✨ **IA Integrada**: Análisis dinámico de habilidades con Google Gemini.
- 📱 **Responsive Design**: Optimizado para todos los dispositivos.
- 🎨 **Estética Dark Mode**: Interfaz técnica y minimalista.

## Instalación y Ejecución

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/jairoSanroman/Jairo-portfolio.git
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Configurar variables de entorno:
   Crea un archivo `.env` y añade tu `GOOGLE_GENAI_API_KEY`.
4. Ejecutar en modo desarrollo:
   ```bash
   npm run dev
   ```

## Despliegue

Este proyecto está listo para ser desplegado en **Vercel** o **Firebase App Hosting**.
